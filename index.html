% Base case: nothing left to move hanoi(0, _, _, _, []).
% Recursive case: move N disks hanoi(N, From, To, Via, Moves) :- N > 0, M is N - 1, hanoi(M, From, Via, To, Before), hanoi(M, Via, To, From, After), append(Before, [move(N, From, To)|After], Moves).

How it fits together

  • From is the source peg (left), To the target (right), Via the spare (center).
  • server.pl answers /api/solve?n=N with the move list Prolog computes.
  • script.js animates each move(Disk, From, To). No server? It runs the same algorithm itself.
